## Problem Statement

Handling college events by hand can be hard when there are events with different names, venues, dates and capacities. Keeping track of event details. Finding them later can be time-consuming and confusing. The College Event Management System offers a way to add, view and search event information using a Java-based console application.

## Scope of the Project

The project is focused on managing details about college events. It lets users add events see all events currently stored and search for a specific event by its name. The system uses Java and ArrayList to hold data. The current version does not include a database, online registration or long-term storage of event data.
Target Users
The main users of this system are college event organizers, student coordinators, club members and faculty members who need to keep track of event details such as event name, venue, date and capacity.

## High-Level Features

Add Event: Enter event ID, name, venue, date and capacity.

View Events: Show all events that are currently saved in the system.

Search Event: Look for an event by typing its name.

Case-Insensitive Search: Find events regardless of whether the lettersre uppercase or lowercase.

Menu-Driven Interface: Use a simple menu to choose actions, like adding, viewing or searching events.
